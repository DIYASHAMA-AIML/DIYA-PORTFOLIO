# Diya Shama — Personal Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop and mobile
- About, skills, projects, experience and contact sections
- Mobile navigation menu
- Dark visual theme with gradient accents

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
Open `index.html` in a web browser.

## Deploy with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your link will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Before submitting
- Replace the sample email, LinkedIn and GitHub links in `index.html` with your real profiles.
- Add real repository links for your projects.
- Check that all skills listed are ones you can explain.
- Open the deployed website and test every navigation link.
